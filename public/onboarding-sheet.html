Quick setup guide
  1. Go to console.cloud.google.com → Create a new project (e.g. "FitOS")
  2. Enable Google Sheets API and Google Drive API on that project
  3. Go to IAM & Admin → Service Accounts → Create service account → any name
  4. Click the service account → Keys → Add Key → JSON → download the file
  5. Create or open your Google Sheet → Share → paste the service account email → Editor
  6. Paste the JSON content and Sheet ID below
