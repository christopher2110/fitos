When you install
Same screens, real
Sheets data.

Unzip the fitos-pwa/ directory, connect your Google credentials, and the same four screens pull live data from your client's Sheet.

# One-time setup
$ npm install
$ cp .env.example .env
# Add your Google credentials
$ npm run dev
# Same screens. Live Sheet data.
What's identical — The whole UI layer
Phone frame, status bar, bottom nav, color palette, typography
ExerciseCard, WeekStrip, CoachNote, HistoryCharts, PipSlider, MessageBubble
Every animation, transition, and tap interaction
What's added when running — Real-app machinery
Service worker + PWA manifest (installable to home screen)
Magic-link JWT auth (no passwords)
Offline queue — logs sets even without signal
SWR cache — data loads instantly on re-open
What's not here — Real backend traffic
This preview calls no APIs — data is inlined
DEMO_MODE=true returns the same mock data server-side
DEMO_MODE=false + Google credentials hits your real Sheet
